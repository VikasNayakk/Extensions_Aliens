# Privacy and data handling

- No chat is collected automatically.
- Input is processed only after the user presses Analyze.
- Without an API key, parsing runs locally in the extension.
- With an API key, the submitted conversation text is sent to OpenAI's API. Do not submit content unless your organization permits it.
- Common secret formats are redacted before remote requests when redaction is enabled. Pattern-based redaction is not infallible.
- The API key is stored in Chrome local extension storage; this is not a vault and is not encrypted by this extension.
- No telemetry, analytics, or remote logging is implemented.
- Speech output is generated by browser SpeechSynthesis.
